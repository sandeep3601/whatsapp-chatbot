# Sandeep Kumar - AI Chat Assistant 🤖

A smart chat assistant project based on Ollama that simulates the chat style of Indian developer Sandeep Kumar for automated responses.

## ✨ Project Overview

This project uses Python and the Ollama framework to create an intelligent chat assistant that can:
- Automatically read chat history from the screen
- Generate replies in the persona and style of Sandeep Kumar
- Automatically paste replies into chat windows
- Support bilingual responses (English and Hindi)

## 🚀 Features

- **Smart Chat Analysis**: Automatically analyzes chat history and generates context-aware responses
- **Role-playing**: Simulates Sandeep Kumar's speaking style and personality
- **Automated Operations**: Automates copying, pasting, and sending actions
- **Multilingual Support**: Supports mixed English and Hindi responses
- **Concise Replies**: Maintains short, natural replies without verbosity
